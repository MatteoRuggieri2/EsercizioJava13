# Comparator

## KeyboardScannerAscDesc

Creare la classe `KeyboardScannerAscDesc` con relativo JUnit di test `KeyboardScannerAscDescTest`.

Chiedere all'utente:

- da quanti elementi ***int*** sarà composto l'array
- i numeri interi da inserire all'interno dell'array
- come dovranno essere ordinati, **ASC** o **DESC**

### Output

Stampare in console l'array di interi ordinato in base alla scelta dell'utente.

#### Consigli

La classe `Arrays` fornisce alcuni metodi come `Arrays.sort(array)` o `Arrays.sort(array, comparator)`.
Il ***comparatore*** è una classe anonima che implementa il comparator.
